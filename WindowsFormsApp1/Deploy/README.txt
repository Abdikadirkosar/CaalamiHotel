TALLAABO 1 — Hubi waxyabaha looga baahdo:
  ✅ Windows 10 ama 11 (64-bit)
  ✅ .NET Framework 4.8
     (Haddaan jirin: https://dotnet.microsoft.com/download/dotnet-framework/net48)
  ✅ SQL Server LocalDB 2019/2022
     (Haddaan jirin: https://aka.ms/sqllocaldb)

TALLAABO 2 — Rakib nidaamka:
  1. Nuqul ZIP-ka geli USB ama Internet (email, Google Drive)
  2. Furi ZIP-ka computer cusub
  3. Laba-guji: 2_Install_On_New_PC.bat
  4. Raac tilmaamaha shaashadda

TALLAABO 3 — Soo geli xogta hore:
  1. Fur nidaamka hal mar (si database loo sameeyo)
  2. Xir nidaamka
  3. Laba-guji: 3_Import_Data.bat
  4. Fur nidaamka — xogta hore waa joogaysaa!

XAALADAHA GAARA:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  • Haddaan xogtu soo gelin: fur nidaamka marka hore, ka dibna soo geli
  • Admin password-ka default: "Admin123" (bedel marka aad bilowdo)
