# 🏨 Hotel Management System

A desktop application built with C# and .NET to efficiently manage hotel operations such as room booking, customer check-in/out, and billing. This system provides a user-friendly interface to streamline daily hotel management tasks.

---

## 🚩 Features

- **Smart Dashboard**: Real-time room occupancy and daily revenue charts.
- **Room Management**: Add, edit, and delete rooms with status tracking (Available, Unavailable, Maintenance).
- **Guest Management**: Store guest details, view current/past stays, and manage Check-In/Check-Out with overdue visual indicators.
- **Audit Logging**: Full audit trail recording all user events (logins, bookings, edits).
- **Search & Filters**: Real-time filtering of lists by name, room number, or status.
- **Professional Design**: Dark navy blue and gold color scheme.

---

## 🛠️ Technology Stack

- **Language**: C#
- **Framework**: .NET Framework 4.8
- **Database**: Microsoft SQL Server LocalDB

---

## 📋 Prerequisites

- Windows OS
- Microsoft SQL Server LocalDB
- Visual Studio 2019 or later

---

## ⚙️ How to Build and Run

1. Open the solution file `Hotel Management System 2.sln` in Visual Studio.
2. Select **Build ➔ Rebuild Solution** from the top menu.
3. Press **Start** (or **F5**) to compile and run the application.
4. Default credentials:
   - **Username**: `Admin`
   - **Password**: `admin`
